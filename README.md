# AgriOS — Open Source ERP for African Agri-SMEs

AgriOS is an open-source, subscription-free ERP designed for African agri-SMEs
and cooperatives. It integrates business operations with supply chain traceability
to improve efficiency, ensure EUDR compliance, and unlock access to finance for
smallholder farmers.

## About

AgriOS is deployed across Kenya, Nigeria, Sierra Leone, South Sudan, Uganda,
and Zambia, supporting 55,000+ smallholder farmers through agri-SMEs and
cooperatives. It is built on the Odoo Community framework and released as a
Digital Public Good.

- **SDGs:** 1 (No Poverty), 2 (Zero Hunger), 8 (Decent Work), 9 (Innovation & Infrastructure)
- **Languages:** English, French, Swahili
- **Solution type:** Web app, API, database
